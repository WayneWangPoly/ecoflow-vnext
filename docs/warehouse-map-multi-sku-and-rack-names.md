# Warehouse Map multi-SKU cells and rack labels

- The row-level `+` now adds another configured SKU position to the selected A/B physical cell.
- Adding a SKU position does not add stock quantity or bypass receiving.
- The first stocktake can continue directly into Barcode setup with the selected location prefilled.
- Owner/Admin Edit layout can change rack display names and category descriptions.
- Rack codes and location codes remain immutable so stock history, scanning and the ledger stay linked.
