Dashboard plain-language meanings:
- NEEDS MAPPING: a SKU, barcode or imported line cannot yet be matched safely.
- MISSING ORDER DETAIL: invoice detail or line items are incomplete and the order cannot be released.
- UNCHANGED: no source fields changed in the latest Ordermentum sync; it is hidden from the action-only Daily control queue.
- Active orders: the current operational workflow excluding completed and cancelled orders, not lifetime history.
